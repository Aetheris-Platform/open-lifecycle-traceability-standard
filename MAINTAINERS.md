# Maintainers

OLTS is currently stewarded by the repository maintainers.

## Current Stewardship

- Steward group: repository maintainers
- GitHub repository: `open-lifecycle-traceability-standard`

## Maintainer Responsibilities

Maintainers are expected to:

- preserve OLTS tool neutrality and vendor neutrality;
- protect source-of-truth boundaries between product repositories, generated artifacts, and OLTS guidance;
- review changes to conformance levels, relationship semantics, schemas, examples, and adopter claim language;
- require compatibility or migration notes when a change could affect adopters;
- moderate Discussions, Issues, and Pull Requests under the Code of Conduct;
- avoid endorsement, certification, compliance, or official-conformance claims unless a future policy defines them;
- record release decisions and public-launch approval in tracked issues or pull requests.

## Contact and Reporting

- General questions and broad feedback: use GitHub Discussions.
- Trackable changes: open a GitHub Issue.
- Pull request review: use the repository pull request workflow.
- Security-sensitive reports: use GitHub private vulnerability reporting or GitHub Security Advisories for this repository when available.

This file should be updated before `v1.0.0` if OLTS moves to a broader steering group, foundation, or multi-maintainer governance model.
